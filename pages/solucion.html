Solución Tecnológica

Cómo EcoSync garantiza la continuidad operacional ante interrupciones de red.

¿Cómo funciona EcoSync?

EcoSync intercepta cada interacción del usuario con formularios empresariales y persiste el estado localmente mediante LocalStorage. Cuando se detecta una interrupción de red, el sistema activa el modo contingencia de forma transparente, garantizando cero pérdida de datos. Al restaurarse la conexión, un motor de sincronización reconoce el estado local y lo prepara para envío al servidor.

Los 3 pilares de EcoSync

01
💾

Auto-persistencia local

Cada campo del formulario es monitorizado. Los cambios se escriben en LocalStorage cada 600ms con un sistema de debounce optimizado. La estructura del draft incluye metadatos de timestamp para auditoría.

  • Serialización JSON automática
  • Sanitización de RUT y email antes de loggear
  • Versionado de draft (ecosync_draft_v1)
02
🔄

Resiliencia de red

El motor de detección de contingencias monitoriza el estado de la conexión. Al detectar una caída, activa el banner de contingencia y bloquea los intentos de sincronización hasta que se restaure la conectividad.

  • Banner naranja de alerta visible
  • Bloqueo de sync en modo offline
  • Contador de eventos de contingencia
03
🔍

Trazabilidad forense

La consola técnica registra cada evento del sistema con timestamp, tipo y descripción. Los logs se persisten en LocalStorage (máx. 500 entradas) y pueden exportarse en formato JSON para auditorías.

  • Tipos: info, warn, error, success
  • PII sanitizado automáticamente
  • Exportación JSON con un clic

Especificaciones técnicas
